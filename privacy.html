Privacy Policy

Effective date: September 22, 2026

Barik Drive Publisher is a private, single-user automation operated solely by its owner. It is not offered as a public service.

Google user data accessed

The application may access file and folder names, metadata, and file contents in the owner's Google Drive as required to publish selected project files and verify the published result.

How data is used

Google Drive data is used only to list, read, create, update, and verify files in the owner's designated project workspace. It is not used for advertising, profiling, or any unrelated purpose.

Storage and security

OAuth credentials and tokens are stored locally on the owner's Barebone server. Published files remain in the owner's Google Drive. Secrets are not placed in public project files or operational logs.

Sharing

Google user data is not sold, transferred, or shared with third parties. The application does not operate an external data service.

Retention and deletion

Published files remain in the owner's Google Drive until the owner updates or deletes them. The owner can revoke the application's access at any time through Google Account security settings.

Google API policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

Questions can be sent to the user-support address displayed on the application's Google OAuth consent screen.
